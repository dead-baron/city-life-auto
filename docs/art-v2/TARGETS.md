# Concept targets (`docs/art-v2/targets/`)

The user's concept art, filed by ID. The art v2 renderer is built to match these (`SPEC.md` has the rules measured
from R1). A letter after the ID (`N1-A`, `N1-B`...) is another sheet or view of the same subject. Nothing here is
drawn into the game directly: the game's art is made in code to look like it.
